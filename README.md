Wrath of the Witty (v1) was a deckbuilding roguelike game where the player would accumulate cards and use them to string together insults in an attempt to mentally destroy their opponents. Cards were split into two categories: Template Cards and Action Cards. Action Cards would contain an insult, insecurity type, and damage value. Template Cards would contain a fill-in-the-blank sentence and execution modifiers. Using randomly drawn Action Cards and Template Cards from their deck, the player would string together powerful insult combos.
